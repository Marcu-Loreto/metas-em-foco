# Metas em Foco

acima um docmento com metas a serem compridas, preciso que elabore um aplicativo quepossa, listas as metas , criar indicativo de completude em %, liste os KPIS e OKRs de cada KPI, crie um dashboard mostrando as metricas de cada KPI com a ideia de cartões , mostrando o  % de completude e area de texto para adicionar informaçoes relevantes. UI do app deve ser suave com tons pasteis e verde musgo. Utilize boas praticas para miontar o dashboard com os indicadores. adicione a opção de relatório final, com exportacao em pdf
